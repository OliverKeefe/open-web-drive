# What is BLOB storage, buckets and AWS S3?

## BLOB Storage
### What Are Objects?
Within the context of BLOB storage, an "Object" is a 
B*inary* L*arge* OB*ject* or BLOB.
These can be anything from documents, photos, videos, 3D models etc...
BLOBs can have any size, format, structure or type. They're just binary representations
of file data after all. 

### What is a Bucket?
A bucket is a collection of related objects, policies and configurations.
These can be thought of as something similar to a Volume (e.g. NFS Mount, Database etc...)
